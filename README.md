# CTRL Magazine

Premium livsstilsmagasin — landing page for Issue 01: The Control Issue.

## Kør lokalt

Åbn `index.html` i browseren, eller start en simpel server:

```bash
npx serve .
```

## Visuel identitet

- **Farver:** Sort (`#0a0a0a`), hvid (`#f5f3ef`), guld (`#c9a962`)
- **Typografi:** IvyPresto Display (rubrikker) og Objectiv Mk1 (brødtekst) via [Adobe Fonts](https://use.typekit.net/pgx4dnl.css)

## Struktur

- Hero — Issue 01
- Manifest — brandets kerneidé
- Sektioner — Style, Gaming, Tech, Interview
- Issue preview — The Control Issue
- Abonnement — e-mail signup (demo)
